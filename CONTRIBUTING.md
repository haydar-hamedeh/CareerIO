# Contributing

Thanks for taking a look. CareerIO is a portfolio project, but issues and pull requests are welcome.

## Setup

1. `npm install`
2. Copy `.env.example` to `.env.local` and fill in your own keys.
3. `npm run dev` and open http://localhost:3000

## Before opening a pull request

1. `npm run lint`
2. `npm run typecheck`
3. `npm run build`

## Rules

- Never commit secrets or `.env*` files (except `.env.example`).
- Never commit real personal data. Demo CVs, people and companies must be synthetic and labelled as demo.
- Keep AI features honest: the model must never invent experience, skills or numbers.
