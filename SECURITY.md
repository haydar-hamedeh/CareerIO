# Security Policy

CareerIO is a demo / portfolio project. It is not a production hiring service.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.
Use GitHub's private vulnerability reporting ("Security" tab → "Report a vulnerability") on this repository.

Include steps to reproduce, the affected route or file, and the impact you expect.
You should get a reply within 7 days.

## Scope

- Authentication and Row Level Security bypasses
- Access to another user's CV, profile or applications
- Prompt-injection that changes a CV score or match ranking
- Secrets or personal data committed to the repository

## Data in this repository

All CVs, candidates, companies and jobs in this repository are **synthetic demo data**.
If you find anything that looks like real personal data, report it and it will be removed.
